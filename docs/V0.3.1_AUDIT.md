# DIRK v0.3.1 RC audit

This release candidate replaces the custom ADV keyboard decoder with the official M5Cardputer >=1.1.1 semantic keyboard API and retains Launcher-proven printable navigation fallbacks. It keeps GPIO5 high before SD access and preserves the render-driven RGB565 DIRK splash.

Truth rules:
- 2.4G reports only the S3 provider initialization.
- GPS present means NMEA bytes were parsed; GPS fix remains a separate runtime state.
- C5 detected means UART activity only. It is NOT proof of 5 GHz operation; the current code must not promote UART traffic to a verified 5G capability.
- No menu text may claim an operation succeeded without a real provider result.

Upstream references checked: M5Stack M5Cardputer Keyboard API, M5Launcher Cardputer ADV support, C5Lab M5MonsterC5/JanOS architecture.
