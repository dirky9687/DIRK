# DIRK v0.3.0 beta notes

## What changed
- Replaced the previous Cardputer keyboard-state dependency with a dedicated Cardputer ADV TCA8418 FIFO polling path using the hardware mapping validated by M5Launcher.
- Navigation: `;`=up, `,`=left, `.`=down, `/`=right, Enter=select, backtick/Backspace=back. Existing letter hotkeys remain available.
- Added a render-driven graphical main menu with Red/Blue accent system, vector module icons, animated context tile, status icon strip, and ambient Matrix-style motion.
- Added an embedded static DIRK logo asset derived from the approved UI render.
- Reworked boot into a POST-style dynamic checklist for keyboard, 2.4 GHz Wi-Fi, BLE, SD/files, GPS UART activity, MonsterC5/5 GHz UART activity, and DIRK core.
- Optional hardware is reported honestly: GPS requires received NMEA bytes; MonsterC5/5 GHz requires observed companion UART traffic.

## First hardware test
1. Build: `pio run -e cardputer-adv`
2. Flash/install the resulting application binary using the same known-good v0.2.2 workflow.
3. Verify `; , . /`, Enter, Backspace/backtick, and W/B/D/C/A/N/S/F/T hotkeys.
4. Verify boot POST results with and without the LoRa/GPS Cap and MonsterC5 attached.

## Validation status
The source was patched against the known-good v0.2.2 archive. This environment does not contain PlatformIO or its cached ESP32 toolchain, so the final compile must be performed on the cyberdeck before this build is considered compile-validated.
