# First Hardware Test

1. Confirm splash appears.
2. Confirm 2.4 / BLE / SD / GPS UART / MonsterC5 status lines are sensible.
3. Confirm physical arrow keys move the main selection.
4. Confirm W/B/D/C/A/N/S/F/T open the expected module.
5. Confirm Settings theme changes header/footer immediately.
6. Confirm brightness, dim and black-screen timing.
7. Confirm first key after dim/black only wakes the display.
8. Confirm Settings -> Wi-Fi Connection can scan and join a test network.
9. Confirm 2.4 GHz recon scan lists APs.
10. With LoRa/GPS Cap installed, confirm GPS status becomes available after NMEA data.
11. With MonsterC5/JanOS installed, confirm 5G does not show present unless UART data is actually observed.

Do not treat a successful compile as hardware validation.
