# DIRK v0.8.0 — Red Attack Learning Labs (SOURCE TEST)

Baseline: DIRK v0.7.19 RED/BLE expansion, which the user reports works on their Cardputer ADV.

## New menu path
Red Team mode > Wi-Fi > Red Operations > Attack Learning Labs.

## Four standalone activities

1. SSID Impersonation Clues (passive observed data): select a saved + authorized AP with Up/Down. Compare other *observed* BSSIDs using exactly the same SSID, including counts per band, differences in channel, and differences in 2.4 GHz reported authentication. A matching name or a security mismatch is not proof of an evil twin: legitimate AP deployments often use multiple BSSIDs, channels and bands. Unknown MonsterC5 5 GHz security details are excluded from confidence claims. Left/Right navigates three pages; Tab exports an aggregate-count CSV to /dirk/reports/identity_lab_<BSSID>.csv. No other AP MACs are exported.
2. PMF Spoofing Tabletop (simulation only): select an authorized saved AP; review whether 2.4 GHz RSN indicates PMF required, PMF optional, or insufficient evidence. A hypothetical unprotected robust management frame is discussed for a protected client. No frames are transmitted and no resilience outcome is measured; 5 GHz PMF is always marked unknown with current MonsterC5 metadata. Left/Right for three pages.
3. WPS PIN Checksum Demonstration (offline): three synthetic seven-digit samples illustrate the last check digit of an eight-digit PIN. No real AP PINs are read, attempted, or stored. Up/Down cycles examples; Left/Right changes the explanation page. This is educational math only.
4. Authorized Test Playbook: four pages covering scope/permission, baseline data, bounded exercises, logs and verification. Left/Right changes steps.

All new content is constrained to pixel y<=108 (footer divider at 117).
